下载桌面端

打开步骤

1 确认左侧 Bridge「在线」
2 点「新标签打开 Studio」（带上 ws://IP:8765）
3 已登录进布局；未登录则先登录一次
4 3D 面板加 LaserScan → /scan，打开 TF
5 Image → /camera/front_up/color/image_raw/compressed

链接格式： https://app.foxglove.dev/<组织>/view?ds=foxglove-websocket&ds.url=ws://板子:8765&layoutId=... · ROS 2 说明

桌面端（更稳）

  1. 安装 Foxglove Desktop
  2. Open connection → Foxglove WebSocket
  3. 填入 WS：ws://192.168.x.x:8765
  4. Open → 添加 3D / LaserScan / TF
  5. 相机：Image → /camera/front_up/color/image_raw/compressed
  6. 点云：先在 设置 打开，再 3D → Point Cloud → /camera/front_up/depth/points

无 iframe 限制，也更少碰到 HTTPS 连 ws:// 的混合内容问题。
