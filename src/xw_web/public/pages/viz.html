打开方式

一键打开（推荐）

用你已登录的组织路径 + 布局。电脑与机器人需在同一局域网。

下载桌面端
1 确认上方 Bridge 为「在线」
2 点「新标签打开 Studio」（会带上本机 ws://IP:8765）
3 若已登录，会直接进你的布局；未登录则先登录一次
4 在 3D 面板加 LaserScan → 话题 /scan，并打开 TF
5 前上相机：加 Image 面板 → /camera/front_up/color/image_raw/compressed

你之前能用的链接格式即： https://app.foxglove.dev/<组织>/view?ds=foxglove-websocket&ds.url=ws://板子:8765&layoutId=... 官方文档见 ROS 2 连接说明。

桌面端

桌面端（更稳）

  1. 安装 Foxglove Desktop
  2. Open connection → Foxglove WebSocket
  3. 填入上面的 WS 地址（如 ws://192.168.x.x:8765）
  4. Open → 添加 3D / LaserScan / TF 面板
  5. 看相机：添加 Image → 话题 /camera/front_up/color/image_raw/compressed
  6. 看点云：先在 设置 打开点云开关，再加 3D → Point Cloud → /camera/front_up/depth/points

桌面端无 iframe 限制，也更少碰到 HTTPS 页面连 ws:// 的混合内容问题。
